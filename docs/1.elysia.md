# Elysia 笔记
- use 与 mount. Elysia mount 是挂载一个创建好的 Elysia 实例, 其本身的展示用例是用于挂载 WinterCG 规范的应用, 比如 Hono. Main 上使用的 OpenAPI 插件不会包含 mount 的应用上的路由. 需要使用 use 方法来挂载.
  - mount 只会为挂载的子实例生成自己的类型，父实例的类型不会自动合并进去。
- 当你使用 plugins 管理 plugin(Elysia Instance), plugins 和 plugin 都要声明 global, 因为它们都是一个 elysia 实例, 需要以此告知其他成员.
- derive, decorate, state 这些可以扩展上下文的方法需要清晰知道生命周期, 可以记录一下.
- 想要获取到 response 时的 status, 可以在 afterHandle 环节通过 set.status 来获取.
- 通过 state 预先设置 mutable 的 store, 在 trace 中记录耗时, 最后在 afterHandle 中打印, 实现函数耗时统计功能.
- 原生 fetch 必须设置 Content-Type 为 application/json, 否则会报错, 因为 body 是 JSON.stringlify 后的, 如果不标识, Server 会 text 处理.
